SECTION 1 — RUNNING THE APPLICATION
------------------------------------------------------------------------

Step 1: Navigate to the project folder
    cd atm-system

Step 2: Start the application
    mvn spring-boot:run

Step 3: Wait until you see this in the console:
    Started AtmSystemApplication in X.XXX seconds

Step 4: Open your browser and go to:
    http://localhost:8080

NOTE: The first time the app starts, it seeds the database automatically.
      You will see all test credentials printed in the console.

To stop the app: press Ctrl+C in the terminal.

FRESH START (reset all data):
    Stop the app → delete the "data/" folder → restart.
    rm -rf data/
    mvn spring-boot:run

     (or full path: jdbc:h2:file:/path/to/atm-system/data/atmdb)

  Useful SQL queries:

  -- View all customers
  SELECT u.user_id, u.name, c.card_number
  FROM atm_users u
  JOIN customers c ON u.id = c.id;

  -- View all ATM cards and their status
  SELECT card_number, expiry_date, is_retained, failed_attempts
  FROM atm_cards;

  -- View all accounts and balances
  SELECT account_number, account_type, balance
  FROM accounts;

  -- View all transactions
  SELECT transaction_id, dtype, amount, status, timestamp
  FROM transactions
  ORDER BY timestamp DESC;

  -- View pending (awaiting approval) transactions
  SELECT transaction_id, amount, status
  FROM transactions
  WHERE status = 'AWAITING_APPROVAL';

  -- View all ATM sessions
  SELECT session_id, state, authenticated, start_time
  FROM atm_sessions;

SECTION 8 — BUSINESS RULES (WHAT THE SYSTEM ENFORCES)
------------------------------------------------------------------------

  CARD / PIN RULES
  - PIN is BCrypt-hashed — never stored in plain text
  - 3 wrong PINs → card is automatically retained
  - Retained card → cannot log in until admin releases it
  - Expired card → cannot log in (must visit branch)

  TRANSACTION RULES
  - Withdrawal: requires sufficient balance
  - Deposit: any positive amount accepted
  - Transfer: requires sufficient balance + valid target account number
  - Large Transaction Threshold: $5,000
      Any single transaction above $5,000 is paused and requires
      Bank Manager approval before money moves

  LARGE TRANSACTION FLOW
  - Customer submits transaction > $5,000
  - Status set to AWAITING_APPROVAL (money NOT moved yet)
  - Customer sees a waiting screen (polls every 5 seconds)
  - Manager approves → money moves → status COMPLETED → customer sees receipt
  - Manager declines → status DECLINED → customer returned to dashboard

  SESSION RULES
  - Each ATM login creates a new session
  - Session is validated on every ATM page (via interceptor)
  - Session ends when customer clicks "End Session" or logs out
  - Card retained sessions are blocked from all ATM pages
